# Grow Robot Arms

A mobile game prototype: you play CRANK, a junkyard villain who smashes the city with robot arms, grows more arms, and takes on the city's heroes.

**Play:** https://chrisli328.github.io/grow-robot-arms/

Best on a phone held upright. On a computer, drag with the mouse or use WASD. Add `?reset=1` to the address to start over from the beginning.

Built with [three.js](https://threejs.org/) and [Rapier](https://rapier.rs/) physics. Font: Lilita One (SIL Open Font License). Licences are in `vendor/`.
