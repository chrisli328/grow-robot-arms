Grow Robot Arms: every UI screen

Every screen, popup and message in the current Unity build, captured from the game itself on a phone (390 x 844) and in a desktop browser window (1440 x 900, where the game plays in a phone-shaped frame). Each card says when the screen shows up, what is on it and which code draws it. "Open in the game" starts the web build in that state; it starts a test game, so it resets the progress saved in that browser.
